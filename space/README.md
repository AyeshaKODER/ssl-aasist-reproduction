# Voiceprint — impersonation risk console

Reproduction of Tak et al., "Automatic speaker verification spoofing and
deepfake detection using wav2vec 2.0 and data augmentation" (Odyssey 2022).
Full training/reproduction code: [GitHub repo](https://github.com/AyeshaKODER/ssl-aasist-reproduction.git).

Upload or record a clip, get a bona-fide/spoof reading, adjust the decision
threshold live.
